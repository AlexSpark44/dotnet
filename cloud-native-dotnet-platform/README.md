# Cloud Native .NET Platform

Opinionated .NET 8 platform skeleton for API + worker workloads, clean architecture layering, cloud-native delivery, and GitHub Pages documentation.

## Structure
- `src/` API, Worker, Application, Domain, Infrastructure
- `tests/` Unit + Integration test projects
- `docs/` GitHub Pages content
- `.github/workflows/` CI and Pages workflows

## Quick start
```bash
docker compose up --build
```
